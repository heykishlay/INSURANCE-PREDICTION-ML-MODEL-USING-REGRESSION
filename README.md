# Insurance Cost Prediction – Regression Model

This project implements a supervised machine learning regression model to predict individual medical insurance charges based on demographic and lifestyle factors.

The workflow includes structured data preprocessing, statistical feature selection, categorical encoding, scaling, and model training using Scikit-learn.

---

## 🎯 Objective

To analyze the impact of factors such as age, BMI, smoking habits, gender, number of children, and geographic region on medical insurance costs and build a predictive regression model.

---

## 🧠 Key Concepts Applied

- Data Cleaning & Preprocessing
- Feature Engineering (BMI Categorization)
- Pearson Correlation (Numeric Feature Analysis)
- Chi-Square Test (Categorical Feature Association)
- One-Hot Encoding
- Train-Test Split
- Regression Modeling
- Model Evaluation

---

## 📊 Features Used

- Age
- BMI
- Children
- Smoking Status
- Gender
- Region
- BMI Category

---

## ⚙️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- SciPy
- Matplotlib
- Seaborn

---

## 📈 Outcome

The final regression model successfully captures the relationship between smoking status, age, BMI, and insurance charges, demonstrating strong predictive performance and highlighting key cost-driving factors.
